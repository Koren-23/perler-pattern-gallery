📤 上傳到拼豆圖庫

選分類、選照片,按上傳。縮圖與清單會自動產生,約 1 分鐘後出現在圖庫。

第一次使用:貼上 GitHub 權杖

權杖只會存在這支手機裡,不會上傳到網站。取得方式見 README「手機上傳」。

分類選錯了?點每組上方的分類名稱就能改。按 ✕ 可拿掉單張照片。
點照片選取要移動的

移過去的照片會改成新分類接續的編號,不會覆蓋原有的照片。刪除要按兩次確認;刪掉的照片仍保留在 GitHub 的歷史紀錄中,誤刪可以救回。網站約 1 分鐘後更新;剛移動或剛上傳的照片,縮圖可能要等網站更新後才看得到。

掃描所有分類,找出重複的照片。「完全相同」「幾乎一樣」會先幫你勾好多的那幾張;「看起來很像」請自己確認(可能是鏡像、換色等故意做的不同版本)。
